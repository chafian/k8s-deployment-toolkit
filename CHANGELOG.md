# Changelog

## 0.1.0 — 2026-10-29

- Add reusable Helm 3 chart for a non-root HTTP application.
- Add schema validation, probes, resource bounds, TLS ingress, HPA, PDB and ServiceMonitor.
- Add Nginx and original Spring Boot examples, environment overlays and Argo CD references.
- Add contract tests, Kubernetes schema validation, isolated cluster tests and GitHub Actions.
- License the toolkit under Apache-2.0.
- Preserve string types in generated resource names and labels; reject Service names beginning with digits.
